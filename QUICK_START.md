# Lollys - Quick Start Guide\n\n## 🚀 Getting Started\n\n### Installation\n\n```bash\ncd \"C:\\Users\\senam\\Downloads\\Lollys\"\nnpm install\n```\n\n### Running the Application\n\n```bash\n# Start the development server\nnpm start\n\n# Or specify a custom port if 4200 is busy\nng serve --port 4300\n```\n\nThe app will be available at `http://localhost:4200` (or your custom port)\n\n---\n\n## 📱 Using the Application\n\n### 1. **Landing Page** (`/`)\n- View features and benefits\n- See how the app works\n- Read customer testimonials\n- Login or Register buttons in navbar\n\n### 2. **Register** (`/register`)\n**Required Fields:**\n- First Name (2+ characters)\n- Last Name (2+ characters)  \n- Email (valid email format)\n- Mobile Number (10-15 digits)\n- Password (8+ characters) ⭐ **IMPORTANT**\n- Confirm Password (must match)\n\n**Example Registration:**\n```\nFirst Name: John\nLast Name: Doe\nEmail: john.doe@example.com\nMobile: 9876543210\nPassword: SecurePass123 (8+ characters)\nConfirm: SecurePass123\n```\n\n### 3. **Login** (`/login`)\n- Email: Use registered email\n- Password: Use registered password (8+ characters)\n\n### 4. **Digital Menu** (`/menu`) - After Login\n**Browse Menu:**\n- Filter by category: Pizza, Burger, Pasta\n- View 8 menu items with descriptions\n- Click \"Customize & Add\" on any item\n\n**Customize Items:**\n- Select Toppings (each adds to price)\n- Adjust Quantity (+/-)\n- Add Special Instructions\n- See Real-time Price Calculation\n- Click \"Add to Cart\"\n\n**Shopping Cart (Right Sidebar):**\n- View all items\n- Remove items\n- See cart total\n- Click \"Proceed to Checkout\"\n\n### 5. **Order Management** (`/orders`) - After Menu\n\n**Step 1: Order Summary**\n- Review all items\n- See item quantities and toppings\n- View price breakdown\n\n**Step 2: Select Delivery Type**\n\n**Option A: Home Delivery 🏠**\n- Enter Street Address\n- Enter City\n- Enter Postal Code\n- Click \"Update Address\"\n- Estimated: 25-35 minutes\n\n**Option B: Click & Collect 🛒**\n- No address required\n- Estimated: 23-35 minutes\n\n**Step 3: Select Restaurant**\n- Choose from nearby restaurants\n- See distance in km\n- View estimated delivery time\n- Click to select restaurant\n\n**Step 4: Select Payment Method**\n\n**Option 1: Credit Card 💳**\n- Card Number (16 digits)\n- Cardholder Name\n- Expiry Date (MM/YY)\n- CVV (3-4 digits)\n\n**Option 2: Debit Card 💳**\n- Same as credit card fields\n\n**Option 3: UPI 📱**\n- UPI ID (e.g., `username@upi`)\n\n**Option 4: Digital Wallet 💰**\n- Select: Google Pay, Apple Pay, PhonePe, or Paytm\n\n**Step 5: Place Order**\n- Click \"Place Order\"\n- Order confirmation (with Order ID)\n- Redirect to view all orders\n\n### 6. **Order History**\n- View all placed orders\n- See order status:\n  - Pending ⏳\n  - Confirmed ✓\n  - Preparing 👨‍🍳\n  - Ready 📦\n  - Delivered ✓\n  - Cancelled ✗\n- Cancel pending orders\n\n---\n\n## 🎨 Features Demo\n\n### Registration Security\n✅ Mobile: Only 10-15 digits accepted\n✅ Email: Must be valid email format\n✅ Password: Must be 8+ characters\n✅ Confirmation: Passwords must match\n\n### Menu Customization\n✅ Pizza Toppings: Extra Cheese, Pepperoni, Vegetables, Mushrooms\n✅ Burger Toppings: Bacon, Extra Patty, Fried Egg, Cheese Slice\n✅ Pasta Toppings: Extra Sauce, Garlic Bread, Parmesan, BBQ Sauce\n✅ Each topping adds to the price\n✅ Special instructions field available\n\n### Location Services\n✅ GPS auto-detection (with permission)\n✅ Falls back to Delhi location\n✅ Shows 4 nearby restaurants:\n   -
